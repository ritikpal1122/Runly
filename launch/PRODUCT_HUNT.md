## Description (260 chars)

```
Runly is a CLI that converts English into Playwright browser tests.
Tests live in your repo as .runly files — git-diffable, PR-reviewable.
Free, open source, works offline. Optional AI self-healing with Claude.
No dashboards, no subscriptions.
```

## First Comment (260 chars — the maker's pitch)

```
Hi PH! I built Runly because enterprise test tools cost $500+/month
and lock your tests in their cloud dashboards. Raw Playwright needs
20 lines of boilerplate per test. I wanted a third option — English
instructions saved as .runly files you can commit to git.

Core features:
✓ English → Playwright automation
✓ .runly test files live in your repo
✓ GitHub Action for 30-sec CI setup
✓ Optional Claude self-healing
✓ Persistent browser (10x faster reruns)
✓ Session reuse (skip login on repeats)
✓ Export to standalone .spec.js files
✓ 100% free and MIT licensed

Would love your feedback — what's missing? 🙏
```
