# Launch Assets

Everything you need to launch Runly publicly, organized by channel.

## Files

| File | Purpose |
|---|---|
| `HACKER_NEWS.md` | Show HN post template + rehearsed Q&A |
| `TWITTER.md` | 8-tweet thread for launch day |
| `PRODUCT_HUNT.md` | Product Hunt listing content |
| `REDDIT.md` | 6 subreddit-specific post templates |
| `DEMO_SCRIPT.md` | 30-second demo GIF recording script |
| `LAUNCH_CHECKLIST.md` | Day-by-day checklist from T-7 to T+7 |

## Quick Launch Plan

**Week before:**
1. Record demo GIF (`DEMO_SCRIPT.md`)
2. Publish to npm (`package.json` is ready)
3. Push to GitHub

**Launch day (Tuesday 9 AM PT):**
1. Hacker News Show HN post
2. Twitter thread (10 AM PT)
3. r/webdev or r/javascript (noon PT)

**Next day:**
1. Product Hunt
2. Other Reddit subs
3. Triage feedback, ship one fix

## Metrics to Beat

| Metric | Target | Stretch |
|---|---|---|
| GitHub stars in 24h | 100 | 500+ |
| HN karma | 50 | 200+ |
| npm installs | 50 | 500+ |

Even if you don't beat these, you shipped something real — that's
the win. Put it on your resume, learn from feedback, keep building.
